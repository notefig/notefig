# Release Notes v0.0.160

- When someone else is editing a paragraph in a synced document, it shows a little paler with a line in their colour, and you can't type there until they're done. Hover to see who.
- Hover another writer's cursor to see their name. The status bar shows who else is here as small coloured dots; hover them for names.
- Agents in a synced document can't change paragraphs a collaborator is editing; they're told who is editing and that nothing was written.
- In a synced project, an edit you just made to a file someone else deletes is no longer lost: the file comes back with your edit.
- Jumping to the next or previous prompt widget now lands it in the middle of the screen instead of pinning it to the top or bottom edge, keeps the caret's line in view when a draft is taller than the screen, and no longer drifts the scroll when the widget is dismissed right after landing
Closes MET-286
