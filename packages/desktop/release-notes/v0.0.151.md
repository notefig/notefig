# Release Notes v0.0.151

- Fixed incorrect focusing of the code viewer container on tab switches
- Fixed incorrect preventing the focus on unloaded chat containers, causing the switch tab hotkeys to be ignored 
- Command palette file search now returns files from all open workspaces, not just the active workspace.
- Workspace file search results are deduplicated when workspaces are nested.
- Clearing the command palette input now immediately removes file search results.
- Fixed an edge case where `rankFileRows` could throw when called with a zero result limit.
Closes MET-255
- The agent can now ask you to pick from options right in the prompt widget, as a single or multiple choice. Click an option, or use ↑ and the arrow keys from the answer field, or type your own answer.
- Questions waiting for your answer show in Needs attention.
- Removed the old in-document question and approval blocks. Any already saved in a document show as plain code blocks.
- Switching workspaces is much faster in projects with an iOS `Pods` or `DerivedData` folder, which are now skipped like `node_modules`.
- Switching tabs no longer rebuilds open documents, so it's much faster for long notes.
- Selecting text and moving the caret in long documents is faster, especially in documents with prompt widgets.
- Large workspaces open, switch and expand folders without freezing the window.
- The app starts with fewer database round trips.
- Fixed multi-line paste into prompt widgets so all pasted lines stay inside the prompt input instead of spilling into the document.
Closes MET-257
- Handling shell start timeouts
