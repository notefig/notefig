# Release Notes v0.0.159

- A numbered list inside a quote keeps its sub-items. Notes indented with tabs, as Obsidian writes them, no longer have their sub-items pulled up into the outer list and renumbered when you edit them.
- Quitting Notefig in a synced project now pushes your last changes, and the others see you leave right away.
- Collaborators whose app crashed or lost its connection no longer linger on the remote.
- Copying text that has a link now keeps the link's address when you paste into a plain-text app, such as a terminal or Claude Code. It's written as `[text](url)`. Everything else copies as it did.
- In a synced project, you now see who else is working in it: a small avatar per person in the status bar, their names and current files in the Remote tool, and their cursors in the documents you have open.
- Fixed: a file deleted with `git rm` while Notefig was closed now syncs when the project is opened.
- Opening a synced project no longer loads the repository's whole history into memory, so the first sync after opening finishes about twice as fast and does far less work on the app's main thread in large repositories.
- When someone else is syncing the same project and branch, your edits reach them within seconds, and theirs reach you. The Remote tool shows who else is syncing now.
- Editing a note now changes only the lines you edited on disk. The rest of the file keeps its formatting (bullet style, indentation, blank lines, the final newline), so `git diff` shows only your change.
