# Release Notes v0.0.130

- **One route.** The app lives at `/`; welcome renders inline when nothing is open. The per-project URL restore, the route param, the loader and the routing helpers are gone. The last session's search string (`?layout=…` and chrome params) is restored at boot.
- **Persisted open set with focus.** `open-workspaces` is a SQLite-backed collection with `focusedAt`. A restart restores every open workspace (collections seeded, watchers armed) before the layout is trusted. Focus only decides what the sidebar shows and where new-item actions land.
- **Tabs resolve their own workspace.** `workspaceOfPath` derives a file tab's workspace by tree membership (deepest nested workspace wins, never a string prefix). `useWorkspaceTabs` is global; each file tab joins its own rows; content watchers are one registry keyed per workspace; editors are no longer disposed on navigation.
- **Opening a project adds to the dock.** `useOpenProject` is the one entry point (welcome, switcher, palette, native menu, error recovery): open + focus, and when none of the project's files is open, land in its scratchpad (MET-135's empty entry, on first open and re-entry). "Open" resolves only once the membership is durable.
- **Agent reads by workspace key.** `useAgentTaskList` matches by `workspaceKey`, so respelled paths still find their sessions. Trust prompts remain per workspace, unchanged.
No user-facing changes. The desktop app behaves as before.
