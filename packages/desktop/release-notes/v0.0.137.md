# Release Notes v0.0.137

- Show the top three agents in the prompt widget's new-conversation menu
- Open the file tree when you create a file or folder from the command palette, so you can name it right away
- Remove the scrollbar that could appear under the tabs and push them out of place, on macOS and Windows
- Show the menu-bar icon in white on a dark menu bar, matching other apps
- Flag finished agent work as needing attention when it completes while the app is in the background
- Stop the caret from landing just above a prompt widget
- Show the caret in the reply box as soon as an agent's reply finishes
- Prompt widgets can highlight what their latest round changed: press the document's chip on a finished widget to mark every block the agent changed with a bar in the editor's gutter. Press it again to hide them.
