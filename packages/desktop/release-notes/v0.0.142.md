# Release Notes v0.0.142

- Widget responses render with the widget in the chat window session.
- added a cache hit graph to th
- **Per-harness chart misread sizes.** A 5M-token harness and two under 400k looked about the same. Usage over time is still stacked areas, but each band is now filled evenly instead of fading out, so its thickness reads as its value.
- **Model shares looked independent.** Each model had its own meter. Shares are now one split bar, then a row per model with its total and share.
- **One harness picker for every view.** It moves to the section header (last) and drives every card: all harnesses side by side, or one harness by model. The breakdown and limits get their own card beside the chart; with all harnesses, every harness's limits show under its name.
- **Cache hits by weekday (new).** A radar of the share of input read from cache per weekday over the range (`cacheHitRate` in shared, `weekdayTokens` in the usage module). It's computed from the hourly buckets' existing token split, so there's no new stored data and past usage is covered.
- The daily pattern stays stacked bars and follows the picker.
