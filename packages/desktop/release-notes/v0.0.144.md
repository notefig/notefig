# Release Notes v0.0.144

- Clicking a widget in the document minimap scrolls to it on the first click again.
- Code blocks have a language picker in their corner, so you can choose how a block is highlighted.
- Code blocks in documents are syntax-highlighted, with the same colours as the code viewer, in both light and dark themes.
- Pick a model or run a skill from the prompt: type `@model:` or `@skill:` in the chat or the prompt widget.
- Saving or resetting a harness in Settings rechecks only that harness, and a reset now rechecks whether it is installed.
- A custom harness's sessions show its name in the chat header even while it is switched off.
