# Release Notes v0.0.114

- Fixed titlebar and icon for Windows
_none_ — unreleased Windows build fixes (MET-157/158), no shipped behavior changes.
- Enables Windows distribution. Handling Windows paths; and, non-POSIX behaviours
- Agent chat tabs now take keyboard focus like any other tab: collapsing the sidebar, or closing settings or the command palette, puts the cursor back in the session's composer.
- Text you select in an agent transcript now seeds the search box, the way a selection in a document does.
- ⌘F with an agent session in view no longer searches for a file named after the session.
- Undo and Redo in the command palette now actually undo and redo in the open document.
