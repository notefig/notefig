# Release Notes v0.0.158

- Bringing forward a tab from another open project now switches the sidebar and the status bar's sync status to that project.
- Opening an old agent session no longer starts the agent on its own. Choose **Load history** to bring back its messages, or send a prompt to continue it.
- Deleting an agent while it is starting up now reliably stops it.
Fixes MET-288.
- Sync no longer stops when someone else edited the same file: the two versions are merged. Where you both changed the same words, the newer edit wins, and your text is listed in the Remote tool and kept on this device.
- One file no longer stops sync for the whole project. When a file can't be merged, the remote's version is used, and yours is listed in the Remote tool and kept on this device. Everything else keeps syncing.
- Undo no longer takes back edits that came in through sync.
- Fixed: a document no longer gets slower to open, paste into or reload the longer the app runs.
