# Release Notes v0.0.102

- The app is now **Notefig**. The window, menus, and everything inside now carry the new name, and your settings, recent workspaces, and window layout migrate over automatically on first launch.
- If you installed before this update, the app file on disk may still be named `Metrists.app` — everything inside it is Notefig. Renaming the file (or re-downloading from [notefig.com](https://notefig.com)) is optional cosmetic cleanup; updates keep working either way.
- New downloads install as `Notefig.app`.
