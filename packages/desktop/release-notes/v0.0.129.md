# Release Notes v0.0.129

- Fixed memory leaks in the initialization of the workspaces and watching external changes in multiple workspaces
Splits the one piece of the service-core work that is **design rather than relocation** out of `met-183-service-core`, so it can ship on its own. No `@notefig/core` dependency, no package moves — this is the workspace-lifetime half only.
- Several workspaces can now be open at once — switching between them no longer stops agents running in the one you left.
- Closing a workspace is now an explicit action (the switcher's X, or the command palette), and warns you if a task is still running.
- Fixed: with more than one workspace open, files from one could show up as loose files in another.
