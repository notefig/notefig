# Release Notes v0.0.149

- A prompt that's working can't be deleted by accident: selecting text around it and deleting, or select-all and Delete, removes everything else and keeps the prompt.
- Backspace after sending a prompt no longer edits its title.
- Select a prompt from the keyboard with Backspace from the line below or Delete from the line above. A selected prompt is tinted the same way whether you selected it from the keyboard or it's inside a text selection. Clicking a prompt never selects it.
- Trying to delete a prompt whose agent is still working shakes it, every time, and says to stop the agent first.
- Typing on a selected prompt goes into its reply field; nothing types into one whose agent is working.
- Dragging a prompt to another spot keeps its answer.
- Cmd-A inside a prompt selects just the prompt first.
- Pasting a copied prompt gives you a fresh one.
Part of MET-248.
- Pressing Escape while an inline prompt is working now stops the agent, wherever your cursor is.
- Backspace in a working prompt no longer removes it.
- Editing a sent prompt no longer leaves its old session linked in the file.
- A file cleared outside the app no longer shows two prompt widgets.
Part of MET-248.
- Markdown images referenced with relative paths containing .. now render instead of showing a broken image
