# Release Notes v0.0.104

- Reworked cross-platform persistence around thinner platform adapters, separating file system, transport, and database responsibilities more cleanly.- Incorporated a WASM-based sqlite implementation for the web platform.
- Standardized the storage direction for web and desktop on a shared TanStack DB-based persistence approach, with platform-specific backends underneath.
- Laid the groundwork for more reliable durable storage of sessions, messages, blob routing, and related app state across reloads and platforms.
- All six namespaces read/write exclusively through db-surface persisted collections.
- Adapter kv and localStorage logic is deleted.
- useKv consumer API remains unchanged.
- Telemetry consent durable-write-before-init ordering preserved and tested.
- Adds Tauri database commands, connection management, error classification, and destructive corruption recovery.
- Adds browser OPFS persistence, cross-tab coordination, and corruption recovery.
- Exposes a shared persistence surface through each platform adapter and adds conformance, IPC, and shim tests.
Changed the internals of the platform adapters for better readability and clearer boundaries. Git client creation is no longer a part of the platform adapter. Fs-level event listeners are registered separately from OS-level ones.
