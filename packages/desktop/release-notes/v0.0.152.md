# Release Notes v0.0.152

- Dictation: hold right ⌥ (right Ctrl on Windows and Linux) in a document, a prompt widget or the agent chat and talk; your words appear as you speak and are inserted when you let go. Speech is processed on your device, and you can turn dictation off in Settings → General.
- Added `Mod+[` and `Mod+]` to cycle between open panes.
- Added `Mod+Alt+Arrow` to focus the pane above, below, left or right of the current one.
Closes MET-261
