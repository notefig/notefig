# Release Notes v0.0.153

- Fixed duplicate prompt widgets after a document rewrite and corrected their markers on disk.
- Agents can show a suggested change as a diff (the before and after, with the changed lines highlighted, side by side when there's room) in chat and in documents; answering a prompt widget, they write it into the document. In a document, select a diff with the arrow keys or Backspace (or reference it from a prompt); clicking or dragging in it selects its code, press Enter or its Edit button to edit its source, and click its file name to open the file.
- The chat history shows an agent's file edits as diffs, closed until you open them.
