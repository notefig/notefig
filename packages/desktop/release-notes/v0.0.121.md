# Release Notes v0.0.121

- Image paths can now be relative to the Markdown file, or, to the workspace root. This mirrors what Obsidian does.
- No longer using temperory files for overriding the OpenCode config to inject the Notefig MCP.
- Fixed arrow key navigation inside the prompt widget and its file lookup dropdown.
- Fixed a rare case where reopening a project could silently create a stray empty scratchpad instead of restoring your last session.
- The AI prompt's text area no longer shows a drag handle of its own.
- Typing in an AI prompt is now seamless with the document: the caret, undo, tab switching and text selection treat the prompt like ordinary content, and your half-typed prompt survives switching tabs.
- Backspace on an empty prompt now removes it, including prompts restored from a saved document — and ⌘-Backspace inside a prompt clears its text instead of deleting the whole widget.
- Arrow keys move in and out of a prompt in a single step, with no phantom cursor stop above it.
- Fixed the editor not scrolling below the fold, and clicks near a split-view divider landing on the resize handle instead of the editor.
