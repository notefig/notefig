# Release Notes v0.0.140

- After choosing a harness or conversation on a prompt, your cursor goes back to the prompt box so you can keep typing.
- Opening a conversation that lives in a split-off pane now clears its unread dot.
- Jumping to a prompt from the minimap or the Everything sidebar now puts your cursor in its prompt box, so you can type right away.
- When the theme is set to System, Notefig now switches between light and dark as soon as your OS does, without a reload.
