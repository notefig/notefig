# Release Notes v0.0.150

- Prompts keep their answers: after restarting the app, each prompt in your documents shows its last answer, summary, changed files or error, instead of an empty box.
- Changes a prompt made stay reviewable after a restart, as long as the document hasn't been edited since.
- Sending from one prompt no longer clears the answers shown in other prompts on the same session.
- Edit and Retry on a restored prompt bring back the prompt exactly as you typed it, skills and other directives included.
- A file a prompt changed opens with its changes highlighted from the prompt's file chip, even after a restart and when that file isn't open.
- A prompt never flashes an empty answer when its turn finishes; it shows the answer as soon as it is saved.
- Retrying a prompt after signing in shows it working again, instead of the old error.
- Restored prompts no longer pulse as unread in the document's minimap after every restart.
- A prompt whose turn disappears, for example when its session is reopened mid-turn, now shows as stopped, matching the sidebar, instead of going back to an empty draft.
- Prompt answers are kept for 7 days.
- A reply that wakes a sleeping session now appears below the conversation in the chat, instead of at the top.
- The debug panel's Session tab lists sessions from every open workspace, not just the one shown in the sidebar.
Closes MET-251.
- Added a command palette item and Cmd+Shift+U shortcut to jump directly to Settings → Usage.
Closes MET-253
- Scratchpads are now always shown at the top of the file tree, regardless of the selected sort order.
Closes MET-254
