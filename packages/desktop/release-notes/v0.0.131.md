# Release Notes v0.0.131

- **Header row.** The sidebar card's top row holds the macOS traffic lights, the workspace name, an attention dot and one tab-like toggle (click anywhere on it). `trafficLightPosition` was calibrated against a capture of the real window; the derivation lives in `titlebar.tsx`.
- **Global rail under the lights.** Logo = Everything view, one chip per open workspace, add, settings at the foot. Icon-only tool tabs (Files / Search / Git / Sessions) with tooltips beside it.
- **Collapse = no column.** The header tweens into the start of the dock's top-left tab strip (always mounted as a zero-width slot so tabs glide instead of jumping) while the column tweens away. The top-left strip is now permanent even with a single tab, so content never moves on collapse.
- **Platform slots.** Windows controls sit at the end of the top strip (`WindowsControlsInline`); in RTL the end-most strip keeps the lights clear instead of the sidebar (`atEnd` threaded through the dock's panel recursion).
- **One `ToolBar`.** Every tool's control row (sort menu, search input, commit controls, new session) shares one height and separator; the file sort menu moved above the tree.
- **One height token.** `--shell-header-height` on the shell root keeps the sidebar header, tab strips and controls aligned; the toggle lands on the same pixel open and closed (measured).
- Fixed ACP plan updates
