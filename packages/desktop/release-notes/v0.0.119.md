# Release Notes v0.0.119

- Selecting text in a document no longer highlights the prompt widget sitting in it — the card, the agent's response and the prompt box all stay clean while the prose around them selects.
- The file tree's create buttons and context menu now use Pierre's icon set, matching the tree itself, and the floating create buttons finally have a background instead of floating transparent over the rows.
- Selecting text in a document no longer highlights the prompt widget sitting in it — the card, the agent's response and the prompt box all stay clean while the prose around them selects.
- The file tree's create buttons and context menu now use Pierre's icon set, matching the tree itself, and the floating create buttons finally have a background instead of floating transparent over the rows.
The package extraction behind these is internal and has no user-facing effect of its own.
- **Prompt widgets stay put.** A prompt you've sent now lives in the document itself, so it survives the agent writing to the file, closing the tab, and restarting the app — instead of disappearing mid-answer. It's stored as a hidden comment that other markdown editors don't render.
- **Continue a conversation after a restart.** Replying in a restored widget resumes the original agent session rather than reporting that it's gone.
- Widgets whose session no longer exists disappear quietly instead of lingering as dead cards.
- The folder the app keeps in your project is now named `.notefig` (it was `.metrists`). Projects you had open before this release start with a fresh one: their existing scratchpads and document history stay on disk under the old `.metrists` folder but are no longer read, so move anything you want to keep into the project yourself. You can delete `.metrists` once you have.
- **Switch workspaces from the sidebar** — the tree bar now shows the current workspace name with a dropdown listing your recent projects (plus Open Folder). Switching restores that workspace's saved tabs and layout, no trip back to the welcome screen.
- **Creation buttons moved to the bottom of the file tree** — New scratchpad, New file, and New folder now float as a compact pill at the bottom end of the sidebar.
- **Scratchpads get a "#" identity** — the scratchpads folder in the tree shows an orange "#" icon, and the scratchpad button and command-palette entry use a matching hash glyph.
