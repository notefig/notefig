# Release Notes v0.0.124

- New notes now get friendly names like "sunny-otter" instead of "untitled-1"
- Fixed line breaks (Shift+Enter) not working inside the AI prompt composer
- Text in the AI prompt composer now highlights with the rest of the document on select-all, like ordinary text
- The notes folder in the sidebar starts expanded so your recent notes are one click away
- Creating a new note opens it in the current tab instead of piling up new tabs
- Polished the agent settings editing experience
- Empty leftover files in the notes folder are now cleaned up on entry regardless of their name
- Reworked the settings UI to be all in one container with scroll spying and URL persistence. 
Settings was a master/detail panel: one section visible at a time, so anything a user didn't already know about went undiscovered, and the open section lived in local state — not linkable, not restorable on reload.
