# Release Notes v0.0.113

- Reference files in agent prompts: type @ in any prompt box, inline widget or chat to pick a workspace file; the agent receives it as attached context.
- Reduced spacing in the command pallet and prompt box file selector
- Filetree files have icons now. MD files' icons have a colour
- Light-mode brand color has changed
