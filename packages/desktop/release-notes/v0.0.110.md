# Release Notes v0.0.110

- Fixed persisting workspace paths; and, re-opening them in the same path
- Selecting text in chat replies now shows the highlight again — markdown-formatted messages were selectable but painted no selection color.
- Typing in the chat composer stays smooth on long conversations; keystrokes no longer re-render the whole transcript.
- The app no longer shows its internal files (`.metrists/`) as untracked changes in your project's git repository.
- Fixed the version panel showing "metadata is inconsistent" for cloned repositories.
- Deleted files and folders now disappear from the file tree immediately (MET-130)
- Clicking the empty space around a document no longer jumps the cursor and scroll position to the end of the file (MET-131)
- Chat messages render their markdown off the main thread, so the app stays responsive while the agent is replying (MET-136)
