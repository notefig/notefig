# Release Notes v0.0.155

- Each agent session now has its own mark, a small shape in its own color. It's on every widget of the session, in the session picker and in the sidebar. Hover it for the harness and session name, or click it to open the chat.
- A widget's session mark also shows when the session needs you and how many prompts came after this one.
- Sidebar rows show one icon each: a file's icon, or a session's mark, which turns into the running or attention icon while the session is busy.
- Edits an agent made in your document are highlighted in its session's color.
- Tooltips appear sooner across the app.
- File references such as `2026-10-23.md` in agent responses are no longer auto-converted to external web links.
Closes MET-281
- Agents now give each session a short name for what it's working on, so you can tell your sessions apart.
- Added keyboard shortcuts for navigating between prompt widgets in the current document: next (⌘↓ / Ctrl+↓), previous (⌘↑ / Ctrl+↑), last (⌘Shift+↓ / Ctrl+Shift+↓), and first (⌘Shift+↑ / Ctrl+Shift+↑).
Closes MET-283
- Push and pull the checked-out branch from the command palette, using your existing git credentials or a pasted token.
Click and Mod+click, and "Open in New Tab" in the right-click menu, now work the same for files, scratchpads, prompts, sessions and links in agent output.
- The checkpoints panel and the agents' history tools are removed.
- Document history is no longer recorded for now.
