# Release Notes v0.0.118

- **Split scratchpad creation from file creation** — Mod+N's "New File" silently created a scratchpad. The palette now has an explicit **New scratchpad** command (keeping Mod+N, pencil-sparkles icon) and **New file** for the inline-naming flow; the file-controls bar gains a dedicated scratchpad button while its file button starts inline naming, matching the palette. The pencil-sparkles glyph is inlined (ISC) since the installed lucide-react predates it.
- "New File" now creates and opens a file instantly — no name or location asked. It lives in a scratchpads area, gets titled from its first heading, and becomes a regular project file when you drag it out of the folder.
- Opening a workspace with nothing restored lands you in a scratchpad instead of an empty screen.
