# Release Notes v0.0.147

- Feedback can now include screenshots: paste or drop up to three images into the message.
- You can now send feedback from inside Notefig: press **⌘⇧M** (**Ctrl+Shift+M** on Windows and Linux), choose **Send Feedback** in the command palette, or use the button in Settings. Tick **Include debug info** to attach the app's debug report.
