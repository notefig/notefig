# Release Notes v0.0.132

- **Finished turns need attention.** A session or prompt widget whose turn finished while you were elsewhere now shows a blue dot in the sidebar; failures and anything the agent is waiting on (a permission, a sign-in) show amber. Opening it is what clears it.
- **One dot on the sidebar.** The sidebar header shows a single indicator — amber if anything anywhere failed or is asking, otherwise blue — instead of a red dot for every waiting run.
- **Marks in place.** The Everything view marks the Prompts and Sessions rows and section titles themselves; only questions the agent is blocked on keep the "Needs attention" card.
- **Prompt widgets point at the document.** A widget's finished turn marks the document it lives in, not the session behind it.
- Fixed prompt cancellation not being flagged as done
- Fixed horizontal scrolling in the prompt widget answers
