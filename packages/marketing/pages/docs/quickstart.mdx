# Quick Start

## Editor (Recommended)

**macOS**

Download from [GitHub releases](https://github.com/metrists/metrists/releases).

**Web (Chrome only)**

Open [app.notefig.com](https://app.notefig.com) in Chrome.

**Other platforms**

Linux and Windows support is in development.

## CLI

Install the CLI:

```bash
npm install -g metrists
```

Initialize a project:

```bash
metrists init
metrists watch
```

The CLI works in any terminal. Use it for automation, CI/CD pipelines, or if you prefer command-line interfaces.
