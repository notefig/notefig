# Download Notefig

Notefig runs as a desktop app and in the browser. Both edit the same plain
markdown files — the desktop app works against folders on your machine, the
web app keeps a workspace in your browser.

## macOS

Apple silicon and Intel, macOS 12 or later.

[Download the macOS app](https://github.com/notefig/notefig/releases/latest)

The app checks for updates on its own, so this is the only download you need.

## Browser

Nothing to install: the web app is the same editor you are reading this in.

[Open the web app](https://app.notefig.com)

## Command line

The CLI builds and publishes a folder of markdown. It is a separate install:

```bash
npm install -g notefig
```

See the [CLI page](/docs/cli) for what it can do.

## Windows and Linux

Not yet. The desktop app is built on Tauri, so both are on the way — the web
app works everywhere in the meantime.
