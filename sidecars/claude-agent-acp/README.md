# claude-agent-acp sidecar

The Claude Code ACP adapter, shipped inside the desktop app (Tauri
`externalBin`) and inside the published CLI, instead of fetched with `npx`
at session start (MET-210).

- `entry.mjs` — the program that gets compiled. See its header.
- `package.json` here (tracked) pins the adapter version — the one place.
  Shared code only knows the sidecar NAME (`SIDECAR_NAMES` in
  harness-config.ts).
- `node_modules/` and `.build/` here are generated by
  `sidecars/bundle.mjs` (an isolated `npm install --omit=optional`, so the
  SDK's ~200 MB native CLI dependency never lands in the tree) and are
  git-ignored.
- Two hosts consume the same bundle:
  - desktop: `packages/desktop/scripts/build-sidecars.mjs` →
    `src-tauri/binaries/claude-agent-acp-<target-triple>[.exe]`, a Node
    single-executable application built from the Node that runs the script;
  - CLI: `packages/cli/esbuild.config.mjs` → `dist/lib/sidecars/claude-agent-acp.cjs`,
    spawned by the `notefig agent` worker with the CLI's own node.
